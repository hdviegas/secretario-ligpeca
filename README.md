# secretario-ligpeca

Secretário pessoal autônomo da Intranet Ligpeça rodando em sessão agendada do Claude Code na
nuvem. A skill e as regras de autonomia estão em `.claude/skills/secretario-ligpeca/SKILL.md`;
o passo a passo de configuração está no repositório `intranet-ligpeca`, em
`docs/agentes/secretario/NUVEM.md` (e a skill original em `docs/agentes/secretario/SKILL.md`).

O token da intranet **não** fica aqui: vem da variável `INTRANET_TOKEN` do ambiente da nuvem.
